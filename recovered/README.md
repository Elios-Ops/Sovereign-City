# Recovered

Preservation area for original recovered applications, kept under their historical names.

Do not rename, reorganize, refactor, or modernize anything in this directory until verification is complete.

Each recovered application subdirectory must document:

- historical name
- source location
- recovery source
- known deployment
- entry point
- dependencies
- verification status
- promotion status

Applications are only promoted to `apps/` after canonical source is identified, the application is verified, and its behavior is documented.
