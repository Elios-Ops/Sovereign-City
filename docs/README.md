# Documentation

This is the living engineering record for the Sovereign City repository.

- `recovery/` — recovery sprint documents, source inventories, board tracking
- `canon/` — canonical naming and application registry
- `architecture/` — ecosystem topology and connection mapping between applications
- `deployment/` — deployment targets and matrices
- `decisions/` — architecture decision records (ADRs)
- `trading/` — TradingView MCP / Pine Script research state (simulation only)
- `directives/` — saved copies of the directives executed against this repository

If a document listed elsewhere in this tree is not yet available, it is represented as a placeholder stating:

```
STATUS:
Authoritative source not yet imported.
```

Missing documentation is never invented.
