## Rules

- Historical names remain preserved. Future branding must never rewrite historical source.
- `AI_APP` is the original canonical source name and must never be renamed to `V1`.
- Version naming begins only with the later source, `AI_APP_V2_EXTRACTED`.
- Do not invent new canon when a name is unclear — flag uncertainty for owner review instead.
- Historical "Ledger AI" references are not mass-renamed to "Gus" until the application is verified, running, and the owner approves brand migration.
