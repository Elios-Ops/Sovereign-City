# Architectural Principle

One repository.

Multiple independent applications.

The repository is **not** one application.

Recovered evidence indicates the ecosystem consisted primarily of standalone HTML / JavaScript applications deployed independently and connected through navigation.

Examples include:

- Ledger AI
- Muskrats.io
- Infinite Agentic Loop
- F.A.M.
- Dashboards
- MCP tooling

Preserve these boundaries.

Do not create a monolithic application.

---

# Recovery Rules

For every recovered component:

1. Preserve source.
2. Identify canonical copy.
3. Verify independently.
4. Trace dependencies.
5. Restore navigation.
6. Promote only after verification.

Never reverse this order.
